# Hew Tang

A personal finance web app that combines trading P&L tracking with daily expense and budget management in one place.

## ✨ Features

**Trading**
- Log daily trades with strategy tags and notes
- Automatic monthly P&L summary with an equity curve
- Stats: win rate, average win/loss, max drawdown

**Expenses & Budget**
- Log daily income/expenses by category
- Set a budget per category with over-budget alerts
- Dashboard with a full financial overview in one screen

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript + Tailwind CSS |
| Backend | Node.js + Express |
| Database | PostgreSQL (Prisma ORM) |
| Charts | Recharts |
| Design | Designed with Google Stitch |

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
